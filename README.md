## Publish on GitHub Pages

1. Create a **public** repository in `samiul-huda1137` named **`samiul-huda1137.github.io`**.
2. Upload the contents of this folder to the root of the `main` branch. Keep `index.html`, `corpnet.html`, `styles.css`, `script.js`, `.nojekyll`, and `assets/` at the repository root.
3. Open the repository's **Settings → Pages**. Under Build and deployment, select **Deploy from a branch**, then **main** and **/(root)**, and save.
4. Wait for the GitHub Pages deployment to finish, then open https://samiul-huda1137.github.io.

No package installation or build command is required. `.nojekyll` disables Jekyll processing. Contact links use email and telephone; messages are not sent or stored by the site. The downloadable resume includes the supplied portrait.
